# Teblocks

The Official Repository of Teblocks

**[Original repo of Techmino](https://github.com/26F-Studio/Techmino) — TeBlocks is a fork of Techmino, updated from the latest upstream. original repo appears to be slowing down, so TeBlocks continues forward with its own direction.**

A free-to-play competitive block-stacking game, built with LÖVE2D as a fork of Techmino's latest upstream — now with ranked matchmaking, battle royale, and multiplayer against players worldwide.

TeBlocks is in active development. Some features (especially ranked) may still have rough edges — bug reports are welcome.

To play: download the client below, then register an account at Teblocks Official website

Features included in the game (as of now, writing this page)
- Skin Direct (Browse skins inside the game and upload them directly, but also have the option to upload and download skins directly from the website)
- Cleaner account management
- Ranked, Casual Lobbies, and more levels to come  
- Overhauled UI
- Customizable controls on both mobile and desktop platforms
- Player reporting and also added reconnection to the game server
- Some funny easter egg 
- So many more to come!
