# Teblocks Skin Creation Guide

This folder contains user block skins for Teblocks.

## Quick Specs
- **Dimensions:** `240 × 90` pixels (PNG format, 32-bit RGBA)
- **Grid:** 8 columns × 3 rows = 24 block tiles
- **Tile Size:** `30 × 30` pixels per tile

---

## 🎨 Layout Overview

### 🌟 Row 1 (Slots 1–8): Prioritized Gameplay Essentials
Skinning **just Row 1** gives you a complete, fully playable custom skin for standard games!
1. **Slot 1 (x: 0–30, y: 0–30):** `Z` Tetromino (Red)
2. **Slot 2 (x: 30–60, y: 0–30):** `S` Tetromino (Green)
3. **Slot 3 (x: 60–90, y: 0–30):** `J` Tetromino (Blue)
4. **Slot 4 (x: 90–120, y: 0–30):** `L` Tetromino (Orange)
5. **Slot 5 (x: 120–150, y: 0–30):** `T` Tetromino (Purple)
6. **Slot 6 (x: 150–180, y: 0–30):** `O` Tetromino (Yellow)
7. **Slot 7 (x: 180–210, y: 0–30):** `I` Tetromino (Cyan)
8. **Slot 8 (x: 210–240, y: 0–30):** `Garbage` / Solid Block (Gray)

---
